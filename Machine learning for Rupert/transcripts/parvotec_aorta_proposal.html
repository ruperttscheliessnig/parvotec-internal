Executive Summary

Parvotec — Aorta Program entwickelt einen ML-optimierten AAV-Vektor mit selektivem Tropismus für vaskuläre glatte Muskelzellen (VSMC) der Tunica Media als Plattform für lokale Gentherapie bei Aortenaneurysma (AAA/TAA) und atherosklerotischer Gefäßkrankheit.

Das Programm nutzt dieselbe ML-Architektur wie das DRG/Schmerz-Programm — das Vascular Fitness Oracle — angepasst für vaskuläre Zellbiologie: VSMC-Transduktionseffizienz, Penetrationstiefe durch die Tunica Intima, systemisches Leber-Off-target und SAXS-basierte Capsid-Stabilitätslabels.

Kernhypothese: Durch DMS-Screening in primären humanen Aorten-VSMC (HUASMC) und aortalen Endothelzellen (HAEC), kombiniert mit ESM-2 Embeddings und Multi-objective Bayesian Optimization, kann in 3 Runden ein AAV-Capsid mit ≥10× verbesserter VSMC-Transduktion gegenüber Wild-type AAV6 bei gleichzeitig minimalem systemischen Leber-Targeting identifiziert werden.

Wettbewerbskontext — Vaskuläre Gentherapie 2026

Kein Mitbewerber kombiniert ML-optimiertes Capsid-Design mit direktem VSMC-Targeting in der Aortenwand:

  • Verve Therapeutics (VERVE-101): LNP-basiertes PCSK9 Base Editing, primär hepatisch. Systemische Anwendung, kein lokales Aorten-Targeting. Phase Ib-Daten 2025.
  • Crispr Therapeutics (CTX310): LNP-PCSK9 Knockdown. Leber-Targeting. Keine vaskuläre Wand-spezifische Transduktion.
  • Renovacor (REN001): AAV9 für kardiale Indikationen (LMNA-DCM). Nicht aorta-spezifisch.
  • AstraZeneca/Moderna mRNA: Systemische Lipid Nanopartikel für ANGPTL3 / PCSK9. Hocheffektiv, aber keine Tissue-Spezifität in der Aortenwand.
  • Parvotec Aorta (intern): Einziger Ansatz mit ML-gesteuertem VSMC-spezifischem AAV-Capsid für lokale periadventitiale Applikation.

Strategischer Vorteil: Lokale periadventitiale Applikation erlaubt hohe Dosen direkt an der Aortenwand ohne systemische Exposition. Keine Leber-Toxizität, kein Immunescape durch Neutralisierungs-Antikörper bei zukünftigen Behandlungen. VSMC-spezifischer AAV als langlebige Alternative zu Stents und chirurgischen Eingriffen.

Vascular Oracle — Datenpipeline

Die vaskuläre Datenpipeline erweitert die DRG-Pipeline um zwei kritische Komponenten: den Dual-Screen (VSMC vs. Leber) als Kern-Differenzierungsmerkmal und die SAXS-Integration aus BM29/ESRF-Messungen als strukturelle Qualitätslabels.

Datenverarbeitungsschritte

  1. Dual-Screen Enrichment Berechnung. VSMC_Score = log2(freq_VSMC_post / freq_pre). EC_Score = log2(freq_EC_post / freq_pre). Leber_Score = log2(freq_Hep_post / freq_pre). Composite = VSMC_Score – 0.5 × Leber_Score. Negative Leber-Selektion: Varianten mit Leber_Score > 2.0 (2× Anreicherung in Leber) werden aus dem Training entfernt.
  2. SAXS-Daten Integration. ATSAS PRIMUS: Guinier-Analyse → Rg, I(0). ATSAS GNOM: P(r) → Dmax. I(0)/Konzentration → Full:Empty kalibriert gegen bekannte Standards (AAV2 full, AAV2 empty). PDI aus DATTOOLS. Normalisierung auf WT-AAV6: ΔRg = (Rg_variant – Rg_WT) / Rg_WT.
  3. Multi-Label Fusion. Join aller 5 Quellen auf Sequenz-ID. Missing Values: Für die 900k Varianten ohne SAXS-Daten (nur Top-100 gemessen): SAXS-Labels werden als NaN geführt. Task-specific Loss maskiert NaN-Werte (kein Gradient von fehlenden Labels).
  4. Train/Val/Test Split. Stratifiziert nach Composite Score Quartil UND Leber_Score Dezil (um sicherzustellen dass Leber-positiv und Leber-negativ Varianten in allen Splits vertreten sind).
  5. ESM-2 Batch Embedding. Identisch zum DRG-Oracle. Full VP1 + Insert → 1280-dim mean pooling. Pre-computed für ~1M Varianten.
  6. Qualitätskontrolle. Technische Replikate Korrelation ≥0.82 (VSMC Screen). SAXS Messung Replikabilität: ΔRg <0.3 nm zwischen zwei unabhängigen SEC-Läufen. Full:Empty Übereinstimmung AUC vs. SAXS: Pearson r ≥ 0.85 auf den 100 gemeinsam gemessenen Varianten.
# Vaskulärer Dual-Screen Composite Score
import numpy as np
import pandas as pd

def compute_vascular_composite(vsmc_enrich: pd.Series,
                                 liver_enrich: pd.Series,
                                 liver_weight: float = 0.5) -> pd.Series:
    """VSMC Enrichment minus gewichtetes Leber-Enrichment."""
    return vsmc_enrich - liver_weight * liver_enrich

def apply_negative_selection(df: pd.DataFrame,
                               liver_col: str = 'liver_enrich',
                               threshold: float = 2.0) -> pd.DataFrame:
    """Entfernt Varianten mit starker Leber-Anreicherung aus dem Training."""
    return df[df[liver_col] <= threshold].copy()

Vascular Oracle — Modell-Spezifikation

Schicht 2: Vascular Fitness Predictor (6-Task)

Erweiterung des DRG-Predictors auf 6 vaskuläre Outputs. Kritische Neuerung: maskierter Loss für SAXS-Features (nur die 100 SAXS-charakterisierten Varianten tragen Gradient zum Rg/F:E/PDI-Head bei).

class VascularFitnessPredictor(nn.Module):
    """
    6-Task Vascular Fitness Predictor.
    Input:  ESM-2 embedding R^1280
    Output: [VSMC_tropism, EC_tropism, liver_off_target, Rg_norm, full_empty, PDI]
    Loss:   Masked MSE — SAXS heads only backprop on labeled samples
    """
    def __init__(self, emb_dim=1280, hidden=[512, 256, 128], dropout=0.15):
        super().__init__()
        layers = []
        in_dim = emb_dim
        for h in hidden:
            layers += [nn.Linear(in_dim, h), nn.ReLU(), nn.Dropout(dropout)]
            in_dim = h
        self.backbone = nn.Sequential(*layers)

        # Biologische Outputs (alle Varianten gelabelt)
        self.head_vsmc   = nn.Sequential(nn.Linear(128,32), nn.ReLU(), nn.Linear(32,1), nn.Sigmoid())
        self.head_ec     = nn.Sequential(nn.Linear(128,32), nn.ReLU(), nn.Linear(32,1), nn.Sigmoid())
        self.head_liver  = nn.Sequential(nn.Linear(128,32), nn.ReLU(), nn.Linear(32,1), nn.Sigmoid())

        # SAXS-basierte Strukturoutputs (nur ~100 Varianten gelabelt)
        self.head_rg     = nn.Sequential(nn.Linear(128,32), nn.ReLU(), nn.Linear(32,1))
        self.head_fe     = nn.Sequential(nn.Linear(128,32), nn.ReLU(), nn.Linear(32,1), nn.Sigmoid())
        self.head_pdi    = nn.Sequential(nn.Linear(128,32), nn.ReLU(), nn.Linear(32,1), nn.Sigmoid())

    def forward(self, x):
        feat = self.backbone(x)
        return {
            'vsmc':  self.head_vsmc(feat),
            'ec':    self.head_ec(feat),
            'liver': self.head_liver(feat),
            'rg':    self.head_rg(feat),
            'fe':    self.head_fe(feat),
            'pdi':   self.head_pdi(feat)
        }

def masked_loss(preds: dict, targets: dict, weights: dict) -> torch.Tensor:
    """Ignoriert NaN-Labels; SAXS-Heads nur auf gelabelten Samples."""
    total = torch.tensor(0.0)
    for key, w in weights.items():
        mask = ~torch.isnan(targets[key])
        if mask.sum() > 0:
            total += w * F.mse_loss(preds[key][mask], targets[key][mask])
    return total

Schicht 3: cVAE mit vaskulärer Negativselektion

Der cVAE Konditionierungsvektor wird auf 6 Zieldimensionen erweitert. Die Leber-Penalty-Dimension wird als negatives Ziel verwendet: hohe Leber-Werte werden bestraft indem der Generator lernt Sequenzen zu erzeugen die weit vom Leber-High-Enrichment-Bereich des Latent Space entfernt sind.

class VascularAAVcVAE(nn.Module):
    """
    cVAE für vaskuläre AAV-Sequenz-Generierung mit Negativselektion.
    Condition-Vektor: [vsmc_goal, ec_goal, liver_penalty, rg_goal, fe_goal, stability_goal]
    Leber-Constraint: sequences with decoder_liver_pred > 0.15 werden gefiltert
    """
    def __init__(self, seq_dim=140, cond_dim=6, latent_dim=128):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(seq_dim + cond_dim, 256), nn.ReLU(),
            nn.Linear(256, 128), nn.ReLU()
        )
        self.fc_mu     = nn.Linear(128, latent_dim)
        self.fc_logvar = nn.Linear(128, latent_dim)
        self.decoder   = nn.Sequential(
            nn.Linear(latent_dim + cond_dim, 256), nn.ReLU(),
            nn.Linear(256, seq_dim)
        )

    def generate_with_constraint(self,
                                  oracle,
                                  targets: dict,
                                  n: int = 500,
                                  liver_max: float = 0.15) -> list[str]:
        """Generiert Sequenzen und filtert Leber-Off-target via Oracle."""
        condition = torch.tensor([[
            targets['vsmc'], targets['ec'], targets['liver'],
            targets.get('rg', 0.5), targets.get('fe', 0.8), targets.get('pdi', 0.1)
        ]])
        candidates = []
        batch = 0
        while len(candidates) < n and batch < 20:
            seqs = self._decode_batch(condition, n=100)
            preds = oracle.predict_batch(seqs)
            # Negativselektion: liver Off-target als hartes Constraint
            valid = [s for s, p in zip(seqs, preds) if p['liver'] <= liver_max]
            candidates.extend(valid)
            batch += 1
        return candidates[:n]

Schicht 4: Multi-objective BO mit Leber-Constraint

# Vaskuläres Multi-objective BO mit hartem Leber-Constraint
from botorch.utils.constraints import NLEConstraint

def run_vascular_bo_iteration(X_obs, Y_obs, ref_point, n_candidates=50):
    """
    Multi-objective BO mit hartem Constraint: Leber Off-target <= 0.15
    Y_obs[:,0]=VSMC  Y_obs[:,1]=EC  Y_obs[:,2]=Leber  (alles maximieren)
    Leber in Y_obs als (1 - liver_score) damit Maximierung = weniger Leber
    """
    model = SingleTaskGP(X_obs, Y_obs[:,:3])  # VSMC, EC, 1-Leber
    mll = ExactMarginalLogLikelihood(model.likelihood, model)
    fit_gpytorch_model(mll)

    # Constraint: Leber Off-target Prediction <= 0.15
    # In Oracle-Koordinaten: (1 - liver) >= 0.85 => liver column (col 2) >= 0.85
    constraints = [NLEConstraint(indices=[2], threshold=0.85)]  # 1-liver >= 0.85

    acq = qExpectedHypervolumeImprovement(
        model=model, ref_point=ref_point,
        partitioning=NondominatedPartitioning(ref_point, Y=Y_obs[is_non_dominated(Y_obs)]),
        constraints=constraints
    )
    candidates, _ = optimize_acqf(acq, bounds=X_bounds, q=n_candidates,
                                   num_restarts=10, raw_samples=512)
    return candidates

Vascular Oracle — Betrieb & API

Standardisierter vaskulärer Optimierungs-Workflow

  1. Kandidaten-Generierung mit Leber-Constraint (Tag 1). cVAE.generate_with_constraint(targets={vsmc:0.85, ec:0.40, liver:0.10, fe:0.80}, n=500, liver_max=0.15). Internes Oracle-Screening aller 500 Kandidaten. Automatische Disqualifikation von Kandidaten mit Oracle-Prediction liver_off_target > 0.15. Composite Score Ranking der verbleibenden Kandidaten.
  2. BO-Kandidaten-Selektion (Tag 1). run_vascular_bo_iteration() mit Leber-Constraint. 50 Embedding-Vektoren die EHVI unter Constraint maximieren. Nearest-Neighbor-Lookup im ESM-2 Embedding Space. Manuelle Review: Biochemische Plausibilität + Positionen der Insertionen überprüfen.
  3. Experimentelle Validierung (Tag 2–28). Synthese der 50 Kandidaten (synthetische Gene, Twist Bioscience). rAAV-Produktion in HEK293T (5 T175/Kandidat). Titer: ddPCR ≥5×10¹² vg/mL. Assays: (a) FACS VSMC vs. EC Transduktion in HUASMC/HAEC (72h Inkubation). (b) Ko-Kultur Assay: HUASMC + THLE-2 Hepatozyten (separate FACS-Channels). (c) AUC Full:Empty für alle 50 Kandidaten. (d) DSF Thermostabilität (Tm). SAXS nur für Top-10 nach Composite Score (kurze Synchrotron-Session).
  4. Leber-Off-target Validierung (Tag 20–28). In vivo Pilot-Leber-Biodistributionsstudie für Top-3 Kandidaten: Intravenöse Injektion in Mäusen (10¹¹ vg/Maus). Nach 7d: qPCR AAV-Genomkopien in Leber vs. Aorta. Go-Kriterium: Leber ≤10× Aorten-Kopien. Dies sichert dass in vitro THLE-2-Assay klinisch relevant ist.
  5. Data Integration & Oracle Update (Tag 28–32). FACS/NGS Rohdaten → Enrichment Scores. SAXS-Rohdaten → ATSAS-Analyse → Rg, F:E, PDI. Merge aller Labels. Re-Training des 6-Task Predictors auf kumulativen Daten. Update BO-Surrogate GP-Modelle. Pareto-Front Update: VSMC × (1-Leber) × EC.
